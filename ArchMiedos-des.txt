# 📁 ARCHIVO DE MIEDOS - Documento de Diseño e Implementación

## 🎯 Visión General
Una aplicación web que funciona como un "archivo anónimo de miedos" con estética retro de oficina de los años 50, pero con animaciones modernas y fluidas. Los usuarios pueden depositar sus miedos anónimamente, explorar los miedos de otros a través de archivadores metálicos interactivos, y dar "apoyos" (likes) para crear comunidad.

---

## 🏗️ Arquitectura Técnica

### Stack Tecnológico
| Componente | Tecnología | Propósito |
|------------|------------|-----------|
| Hosting | Cloudflare Pages | Servir HTML/CSS/JS |
| Backend | Cloudflare Workers | API y lógica de negocio |
| Base de Datos | Cloudflare D1 | Almacenar miedos y likes |
| IA/Moderación | Cloudflare AI Gateway (Llama Guard 3 8B) | Filtrar contenido ofensivo |

## 🗄️ Base de Datos (D1)

### Esquema
```sql
-- Tabla principal de miedos
CREATE TABLE fears (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  content TEXT NOT NULL,
  first_letter CHAR(1) GENERATED ALWAYS AS (UPPER(SUBSTR(content, 1, 1))) STORED,
  likes INTEGER DEFAULT 0,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  is_approved BOOLEAN DEFAULT 0,
  is_reported BOOLEAN DEFAULT 0,
  moderation_comment TEXT
);

-- Índices para búsquedas rápidas
CREATE INDEX idx_first_letter ON fears(first_letter);
CREATE INDEX idx_approved ON fears(is_approved);
CREATE INDEX idx_created_at ON fears(created_at);

-- Tabla de reportes (para el panel de admin)
CREATE TABLE reports (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  fear_id INTEGER,
  reason TEXT,
  reported_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (fear_id) REFERENCES fears(id)
);
```

## 🎨 Diseño de Interfaz

### 1. Página de Ingreso (`index.html`)

**Layout:**
- **Header**: Título "Archivo de Miedos" con tipografía retro (ej: 'Special Elite' de Google Fonts)
- **Hero Section**: Imagen de fondo sutil (papel envejecido o estantería de archivo)
- **Formulario**: 
  - Área de texto de 2000 caracteres con contador
  - Placeholder: *"Escribe aquí tu miedo... deposítalo en el archivo y libérate"*
  - Botón: "Depositar en el Archivo" (animación de pulsación)
- **Footer**: Enlace a "Explorar el Archivo" con ícono de flecha

**Estilo Moderno + Retro:**
- Fuente principal moderna (ej: 'Inter' o 'Nunito') para contraste
- Elementos retro: bordes decorativos, sombras de papel, sellos
- Animaciones: hover suave, transiciones elegantes, efecto de tinta al escribir

### 2. Página del Archivo (`archive.html`)

**Layout Principal:**
- **Header**: Logo + "Archivo de Miedos" + botón "Depositar tu miedo"
- **Grid de Archivadores**: 3x3 con efecto de profundidad y sombras

**Cada Archivador:**
```html
<div class="filing-cabinet" data-letter="A-C">
  <div class="cabinet-drawer">
    <div class="drawer-handle"></div>
    <div class="drawer-label">A-C</div>
    <div class="drawer-count">42 miedos</div>
  </div>
  <div class="cabinet-shadow"></div>
</div>
```

**Interacción:**
- Hover: El cajón se desliza ligeramente (2-3px) y la sombra se intensifica
- Click: Animación de apertura (transición suave de 0.5s)
- El cajón se "abre" revelando un modal con el contenido

**Modal de Contenido:**
- Header: "Archivo A-C" con contador
- Barra de búsqueda (filtrar por palabra clave)
- Grid de tarjetas (fichas de catálogo):
  - Cada ficha muestra: texto del miedo, fecha (formato "depositado el 15/08/2026"), botón de apoyo
  - Efecto de tarjeta de biblioteca con borde perforado
  - Animación de entrada (fade-in escalonado)

**Estilo:**
- Fondo: verde oliva suave o gris acero
- Archivadores: metálicos con reflejos y textura sutil
- Tarjetas: blanco crema con borde punteado
- Tipografía: Courier New para números, moderna para textos

### 3. Panel de Administración (`admin.html`)

**Layout:**
- **Sidebar**: Navegación (Pendientes, Aprobados, Reportados, Estadísticas)
- **Contenido Principal**: Tabla o lista de miedos con acciones
- **Filtros**: Por estado, fecha, letra

**Acciones por Miedo:**
- ✅ Aprobar / ❌ Rechazar
- 🗑️ Eliminar
- 👁️ Ver detalle (texto completo, fecha, IP anónima)

**Estadísticas (Dashboard):**
- Total de miedos depositados
- Total de apoyos dados
- Miedos más populares (top 5)
- Actividad en los últimos 7 días (gráfico simple)

**Seguridad:**
- Autenticación básica con usuario/contraseña (Cloudflare Access o HTTP Auth)
- Todas las rutas de admin protegidas

## 🧠 Lógica del Backend (Worker)

### Endpoints API

#### Miedos Públicos
```javascript
// GET /api/fears?letter=A&limit=20&offset=0
// Obtiene miedos aprobados por letra
GET /api/fears

// GET /api/fears/search?q=araña&limit=20
// Busca miedos por palabra clave
GET /api/fears/search

// POST /api/fears
// Deposita un nuevo miedo (requiere moderación)
Body: { content: "texto del miedo" }
Response: { id: 123, status: "pending_approval" }

// POST /api/fears/:id/like
// Añade un apoyo (like) a un miedo
Response: { likes: 42 }

// GET /api/fears/random
// Obtiene un miedo aleatorio (para la página de inicio)
```

#### Administración
```javascript
// GET /api/admin/fears?status=pending&limit=20
// Lista miedos para moderar

// PUT /api/admin/fears/:id
// Actualiza estado de un miedo
Body: { status: "approved" | "rejected", comment: "motivo" }

// DELETE /api/admin/fears/:id
// Elimina un miedo permanentemente

// GET /api/admin/stats
// Obtiene estadísticas del sistema
```

### Integración con IA (Moderación)

```javascript
// services/ai.js
export async function moderateContent(content) {
  const response = await fetch('https://gateway.ai.cloudflare.com/v1/...', {
    method: 'POST',
    headers: { 'Authorization': `Bearer ${API_KEY}` },
    body: JSON.stringify({
      model: '@cf/meta/llama-guard-3-8b',
      messages: [
        {
          role: 'system',
          content: 'Eres un moderador de contenido. Determina si el siguiente texto contiene: odio, violencia, spam, acoso, o contenido inapropiado. Responde con "SAFE" si es seguro, o "UNSAFE" si no lo es.'
        },
        {
          role: 'user',
          content: content
        }
      ]
    })
  });
  
  const result = await response.json();
  return result.is_safe; // true o false
}
```

### Flujo de Depositar un Miedo

1. Usuario envía texto desde el frontend
2. Worker recibe petición POST `/api/fears`
3. Valida longitud (mínimo 10, máximo 2000 caracteres)
4. Envía a IA para moderación (async)
5. Si es seguro:
   - Guarda en D1 con `is_approved = 1`
   - Devuelve ID y estado "approved"
6. Si es inseguro:
   - Guarda en D1 con `is_approved = 0`
   - Registra en tabla de reportes
   - Devuelve mensaje de "en revisión"
7. El usuario ve confirmación: *"Tu miedo ha sido depositado en el archivo"*

## 📦 Instalación y Configuración

### Requisitos Previos
- Cuenta de Cloudflare
- Node.js instalado
- Wrangler CLI (`npm install -g wrangler`)

### Pasos de Configuración

1. **Crear proyecto**
```bash
mkdir archivo-de-miedos
cd archivo-de-miedos
wrangler init
```

2. **Configurar D1**
```bash
wrangler d1 create archivo-de-miedos-db
wrangler d1 execute archivo-de-miedos-db --file=./database/schema.sql
```

3. **Configurar AI Gateway**
- Ir a Cloudflare Dashboard → AI → AI Gateway
- Crear gateway "archivo-miedos"
- Obtener API key

4. **Configurar Variables de Entorno**
En `wrangler.toml`:
```toml
name = "archivo-de-miedos"
main = "src/index.js"
compatibility_date = "2024-08-08"

[[d1_databases]]
binding = "DB"
database_name = "archivo-de-miedos-db"
database_id = "tu-database-id"

[vars]
AI_GATEWAY_URL = "https://gateway.ai.cloudflare.com/v1/..."
AI_API_KEY = "tu-api-key"
ADMIN_USERNAME = "admin"
ADMIN_PASSWORD_HASH = "hash-de-password"
```

5. **Desplegar Worker**
```bash
wrangler deploy
```

6. **Desplegar Pages**
- Conectar repositorio de GitHub en Cloudflare Pages
- Configurar build (si usas build tool) o deploy directo

## 🔒 Consideraciones de Seguridad

1. **Validación de entrada**: Sanitizar texto (escapar HTML)
2. **Rate limiting**: Máximo 5 miedos por IP en 24h
3. **Autenticación admin**: HTTP Basic Auth o Cloudflare Access
4. **HTTPS**: Forzado por defecto en Cloudflare
5. **CSRF**: Tokens en formularios
6. **Moderación IA**: Bloquear automáticamente contenido ofensivo
